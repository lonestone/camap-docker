# Points indécis : synthèse des suggestions (FR)

Traduction française du tableau « Summary of suggestions » de [UNDECIDED.md](UNDECIDED.md), avec un peu de contexte pour chaque ligne.

- **Contexte** : ce que fait le code aujourd'hui (résumé de « Current behavior » dans UNDECIDED.md, où se trouvent les références au code).
- **Suggestion** : la résolution proposée après lecture du code. C'est une proposition, pas une décision : rien n'est tranché tant que le product owner n'a pas répondu.

Les lignes sont triées par niveau de confiance, du plus faible au plus élevé, puis par domaine (ACC comptes, GRP groupes, CAT catalogues, DIS distributions, ORD commandes, PAY paiements, COM communication, ADM administration, NAV navigation) :
- confiance **faible** : UND-011 à UND-114 (5 lignes), à arbitrer en priorité ;
- confiance **moyenne** : UND-001 à UND-119 (49 lignes) ;
- confiance **élevée** : UND-004 à UND-118 (65 lignes).
