# Points indécis : état des décisions (FR)

Synthèse en français de [UNDECIDED.md](UNDECIDED.md) (où se trouvent les références au code). Sur 121 points, les 121 sont décidés.

- **Contexte** : ce que fait le code aujourd'hui (résumé de « Current behavior » dans UNDECIDED.md).
- **Décision** : ce que le product owner a tranché ; le détail et la date sont dans UNDECIDED.md et dans les specs.

Seuls les points décidés qui changent le comportement pour corriger une faille de sécurité (34) ou un bug (52) sont repris ici. Les 35 autres (comportement actuel conservé, simple précision de la spec, suppression de code mort, petite évolution) restent consultables dans UNDECIDED.md.

## Points encore indécis

Aucun : tous les points sont décidés.
