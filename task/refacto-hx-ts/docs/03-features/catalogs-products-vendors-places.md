# Catalogs, products, vendors, places, stock, files

## 1. Scope

Catalogs (UI label "contrat"), products, stock tracking, vendors (producteurs, including claim/profile/dashboard), places (delivery locations), and file/document/media storage tied to these entities. Subscriptions and orders on catalogs are in `orders-subscriptions.md`; distributions in `distributions-volunteers.md`.

Ownership summary: the whole back-office CRUD (catalog, product, vendor create, place, documents, media, CSV import/export, stock config) is Haxe only. TS owns read-only GraphQL for catalog/product/vendor/place, the vendor self-service dashboard and public profile, image upload (product/vendor/vendor gallery), generic PDF document create/delete, and a few React widgets embedded in Haxe pages.

## 2. Concepts & glossary terms

- **Catalog** (UI "contrat"): belongs to one group and one vendor, has a date window and a type: `0` = constant orders (classic AMAP contract), `1` = variable orders (`camap-hx/src/db/Catalog.hx:18-54`, `camap-ts/packages/api-core/src/vendors/catalog.interface.ts:1-4`). Products belong to exactly one catalog (`camap-hx/src/db/Product.hx:18`).
- **Vendor** (producteur): shared record across groups (`camap-hx/src/controller/Vendor.hx:68`, message "fiches producteurs partagées entre les AMAP"). Catalogs link a group to a vendor. A vendor can be "claimed" by a user (`Vendor.user`) (`camap-hx/src/db/Vendor.hx:21-22`, `:214`).
- **Place**: per-group delivery location with optional lat/lng (`camap-hx/src/db/Place.hx:8-30`).
- **Stock**: per product, 3 tracking modes (Disabled/Global/PerDistribution) and 3 per-distribution sub-modes, active only when catalog flag `StockManagement` is set (`camap-hx/src/db/Product.hx:28-30`, `camap-hx/src/db/Catalog.hx:133`, `camap-hx/common/Common.hx:90-138`).
- **File / EntityFile**: binary blobs in table `File`, linked to entities through `EntityFile` (entityType, entityId, documentType, `data` = visibility) (`camap-hx/src/controller/Documents.hx:155-159`, `camap-hx/src/controller/Media.hx:119-125`).
- **Catalog flags** (bit enum): `UsersCanOrder, StockManagement, PercentageOnOrders, DisplayPricesOnGroupPage, NotifyVendorOnOrderEnd, NotifyContactOnOrderEnd` (`camap-hx/src/db/Catalog.hx:8-15`); TS knows only the first three (`camap-ts/packages/api-core/src/vendors/entities/catalog.entity.ts:20-24`, duplicated `camap-ts/packages/api-core/src/vendors/services/catalogs.service.ts:13-18`).
- **Vendor disabled reasons**: `IncompleteLegalInfos | NotCompliantWithPolicy | Banned`.
- **Claimed vendor**: `Vendor.user` set; only the owner may edit (rule 35).
- **Units**: Piece, Kilogram, Gram, Litre, Centilitre, Millilitre (`camap-hx/common/Common.hx:90-97`).
- **Product flags**: `organic`, `variablePrice`, `multiWeight`, `bulk`.
- **ProductDistributionStock**: rows holding per-period stock.

## 4. Business rules

### Catalogs
1. Types: 0 constant, 1 variable (`camap-hx/src/db/Catalog.hx:53-54`).
2. Flags: new catalog starts with `UsersCanOrder` set (`camap-hx/src/db/Catalog.hx:63`).
3. Dates are normalised on insert/update: start 00:00:00, end 23:59:59 (`camap-hx/src/db/Catalog.hx:341-351`). Start must be <= end (`camap-hx/src/service/CatalogService.hx:118-120`). All existing distributions must lie inside [start, end of day 23:59] (`camap-hx/src/service/CatalogService.hx:123-135`).
4. "Active" = start < now < end (`camap-hx/src/db/Catalog.hx:108-111`). Visible in shop = active && `UsersCanOrder` (`:101-106`). Open to orders: constant = visible; variable = visible and at least one Distribution of the catalog with `orderStartDate <= now < orderEndDate` (`:116-126`).
5. Default creation values: name "Contrat AMAP classique|variable - <vendor>", start now, end now+365.25 d (`camap-hx/src/service/CatalogService.hx:89-91`). Contact (`userId`) required in form (`:103`). Percentage fields removed from the form (`:36-37`) and `hasPercentageOnOrders()` hard-coded false (`camap-hx/src/db/Catalog.hx:128-131`; "removal 1 Feb 2023" banner `camap-hx/src/controller/ContractAdmin.hx:83-88`). TS `hasPercentageOnOrders` honours flag + `percentageValue` (`camap-ts/packages/api-core/src/vendors/services/catalogs.service.ts:146-153`, `computeFees` `:169-178`), and `ProductEntity.getPriceWithMargins` has no flag check (`camap-ts/packages/api-core/src/vendors/entities/product.entity.ts:105-111`).
6. Product price/qt/unit are frozen once the product has any UserOrder (any status): price field replaced by read-only text, server re-checks (`camap-hx/src/controller/Product.hx:40-83`). Workaround: "copyAndDiscard" (`camap-hx/src/controller/Product.hx:169-184`).
7. Order window settings: constant catalog form hides `orderStartDaysBeforeDistrib` and the min-order fields; `orderEndHoursBeforeDistrib` becomes "min delay to enter a subscription" and falls back to 72 if empty/0 (`camap-hx/src/service/CatalogService.hx:49-60,169-177`). Variable catalog: `orderStartDaysBeforeDistrib` cannot be 0 (empty = use distribution-cycle default) (`:141-145`). TS `CatalogsService.create` defaults `orderEndHoursBeforeDistrib` to 24 and discards the `setFlag` result (`camap-ts/packages/api-core/src/vendors/services/catalogs.service.ts:206-226`, `:221`; `setFlag` pure in `camap-ts/packages/api-core/src/common/haxeCompat.ts:18-20`).
8. Changing `orderStartDays`/`orderEndHours` on edit rewrites `orderStartDate`/`orderEndDate` of ALL future distributions of the catalog, overwriting customisations (`camap-hx/src/service/CatalogService.hx:238-269`, `camap-hx/src/controller/ContractAdmin.hx:122-126`).
9. Variable catalogs: minimums `distribMinOrdersTotal` / `catalogMinOrdersTotal` (EUR); `hasConstraints` = variable and either > 0 (`camap-hx/src/db/Catalog.hx:141-143`). Setting `distribMinOrdersTotal==0` wipes absence data (`camap-hx/src/service/CatalogService.hx:152-156`). Warning if `catalogMinOrdersTotal>0` (`:158-160`).
10. Notifications: variable catalogs always notify the vendor at order end; flag hidden for them (`camap-hx/src/db/Catalog.hx:162-164`, `camap-hx/src/service/CatalogService.hx:66-69`).
11. Duplicate: copies name/dates/contact/description/flags/vendor/percentages/orderEndHours/absentDistribsMaxNb; absence dates not copied (`camap-hx/src/controller/ContractAdmin.hx:823-824` commented); type selectable; variable target gets orderStartDays = source's or 365 (`:810-834`). Products: none/all/active only via `ProductService.duplicate` (stock tracking reset to Disabled) (`:860-876`, `camap-hx/src/service/ProductService.hx:73-75`). Distributions copied only for super-admin/group manager (`:878-891`). Volunteer roles copied (`:894-903`). Rights: contact (or current user) gets `ContractAdmin(newId)` (`:842-858`). `updatePrices` dereferences `args.d.id` though `args.d` is only set for variable catalogs (`:775`, `:758-765`).
12. Create (`Contract.doInsert`): volunteer roles created for `distributorNum` (`camap-hx/src/controller/Contract.hx:162`); vendor's user auto-joined to group (`:165-167`); contact receives `ContractAdmin(id)`+`Messages`+`Membership` rights (`:168-174`).
13. Delete: only `canManageAllContracts`; blocked if sum(order qty)>0; removes contact's right and volunteer roles; the Haxe comment claims products/orders/distributions are deleted too but code only deletes roles then the catalog (`camap-hx/src/controller/ContractAdmin.hx:1166-1204`; cascade presumably DB-side, unverified).
14. Absences: available when constant, or variable with `distribMinOrdersTotal>0`, and `maxNb>0` with both dates (`camap-hx/src/db/Catalog.hx:145-152`). Validation: if `maxNb>0` dates required; start<end; `maxNb` <= number of distributions in the window; if window == catalog period, `maxNb` < total; window inside catalog dates (`camap-hx/src/service/CatalogService.hx:197-233`).
15. Catalog document visibility: subscriber sees all; group member sees all except 'subscribers'; others only 'public' (`camap-hx/src/db/Catalog.hx:310-331`). TS `Catalog.documents` field always returns all documents because `canManageCatalog` is not awaited (`camap-ts/packages/api-core/src/vendors/resolvers/catalogs.resolver.ts:173`, intended logic `:175-193`).
16. `Catalog.check()`: warns on invalid UTF-8 in description and product ref/name/desc (`camap-hx/src/db/Catalog.hx:185-203`).
17. TS price: percentage fees applied in `Product.price` (`camap-ts/packages/api-core/src/vendors/resolvers/products.resolver.ts:100-112`).

### Products
18. Fields: name(128), ref(32), price (TTC, 2 decimals), vat(%), desc, qt, unitType, stockTracking, stockTrackingPerDistrib, stock, organic, variablePrice, multiWeight, bulk, image, active (`camap-hx/src/db/Product.hx:14-40`, `camap-hx/common/Common.hx:90-97`). Defaults: vat 5.5, unit Piece, qt 1, active true (`camap-hx/src/db/Product.hx:42-54`). `qt==0` stored as null; vat null -> 0 (`:269-273,282`).
19. Price is TTC (`camap-hx/src/db/Product.hx:20`). HT = TTC/(1+vat/100) (`camap-hx/src/service/ProductService.hx:51-53`). `vatValue` = price - price/(1+vat/100) (`camap-hx/src/db/Product.hx:232`).
20. VAT choices come from the group's `vatRates` JSON (default "TVA alimentaire" 5.5, "TVA standard" 20, auto-created on parse failure) (`camap-hx/src/db/Group.hx:425-435`, `camap-hx/src/service/ProductService.hx:131-139`). ### Stock
28. Stock is editable/visible only when catalog flag `StockManagement` is on, else stock fields are removed from the form (`camap-hx/src/service/ProductService.hx:111-127`). TS forces `stockTracking=Disabled` when the flag is off (`camap-ts/packages/api-core/src/vendors/resolvers/products.resolver.ts:142-151`).
29. Modes: Disabled (always available); Global (one stock for the whole catalog, all orders with qty>0 decrement); PerDistribution with AlwaysTheSame (`product.stock` per distribution), FrequencyBased (stock only every Nth distribution from a start distribution: index % frequencyRatio == 0), PerPeriod (rows `ProductDistributionStock` with start/end distribution; first period containing the distribution's date, else 0) (`camap-hx/src/db/Product.hx:64-125`, `camap-hx/common/Common.hx:103-140`).
30. Available stock = distribStock - sum(orders qty>0); multiWeight counts 1 per order line; clamped to 0 unless `alwaysPositive=false`; null when no tracking or stock==null (`camap-hx/src/db/Product.hx:147-181`).
31. Saving a product deletes and rewrites all `ProductDistributionStock` rows (`camap-hx/src/service/ProductService.hx:150`). FrequencyBased writes one row with startDistribution=endDistribution (`:159-169`); PerPeriod writes one row per submitted period (`:171-185`). Both distributions must belong to the product's catalog (`camap-hx/src/db/ProductDistributionStock.hx:26-33`).
32. Validation on save: stock required when tracking on; for every future distribution of the catalog the available stock must not be negative, else error with the minimum stock (`camap-hx/src/service/ProductService.hx:207-222`). Catalog save only warns when a tracked product has no stock (`camap-hx/src/service/CatalogService.hx:185-193`). The stock form widget validates raw params `<form>_stock_AlwaysTheSame`, `_stock_FrequencyBased`, `_firstDistrib`, `_frequencyRatio` (`camap-hx/src/form/StockTrackingPerDistribForm.hx:36-70`; used `camap-hx/src/service/ProductService.hx:119`; frequency ratios 1/2, 1/3, 1/4).
33. `StockTool.dispatch` / `dispatchOffers` split integer stock across groups/offers (`camap-hx/src/tools/StockTool.hx:16-80`); usages not traced (unverified).
34. Duplicating a product resets stock tracking to Disabled and perDistrib null (`camap-hx/src/service/ProductService.hx:73-75`); `Product.clone` (copyAndDiscard) keeps stock config (`camap-hx/src/db/Product.hx:312-314`); `ProductDistributionStock` rows are not copied by either.

## 5. Flows

1. Create catalog (HX): `/contract/defineVendor` -> found: `/contract/insertChoose/:v`, not found: `/contract/insertVendor` (create + geocode) -> insertChoose -> `/contract/insert/:v?type=` -> checkFormData -> insert -> roles/rights -> `/contractAdmin/view/:id` (`camap-hx/src/controller/Contract.hx:41-183`).
2. Edit product: `/product/edit/:id` -> form (`ProductService.getForm`) -> toSpod -> `updateProductStocksConfiguration` -> price/qt/unit freeze check -> `ProductService.check` -> update (`camap-hx/src/controller/Product.hx:71-91`).
3. Vendor self-service (TS): HX page `/vendor/dashboard` mounts React `vendorDashboard`, tabs edit/contracts/distributions/documents/images (`camap-ts/packages/front-core/src/modules/vendorDashboard/VendorDashboard.module.tsx:202-228`) -> GraphQL `updateVendor`/`claimVendor`/`consolidateVendors`/`createDocument`/`setVendorImage`.
4. Public vendor page: `/vendor/view/:id` -> React `vendorProfile` (`camap-hx/src/controller/Vendor.hx:22-38`, `camap-ts/packages/front-core/src/modules/vendorProfile/VendorProfile.module.tsx:115-127`).
5. CSA catalog subscription page (TS front on HX REST): `csaCatalog` module calls `/catalog/:id`, `/catalog/stocksPerProductDistribution/:id`, `/catalog/catalogAbsences/:id` and `/subscription` (`camap-ts/packages/front-core/src/modules/csaCatalog/requests.tsx:17-105`).
6. Stock availability: UI -> `GET /api/catalog/stocksPerProductDistribution` -> `Product.getAvailableStock` per future distribution (`camap-hx/src/controller/api/Catalog.hx:57-72`).

## 6. Ownership hx vs ts

| area | HX | TS |
|---|---|---|
| Catalog CRUD, duplicate, delete, absences | full | read only (`catalog`, `getActiveCatalogs`) |
| Catalog REST for CSA UI | `/api/catalog` | consumed by `csaCatalog` module |
| Product CRUD, CSV, stock config | full | image upload + read fields |
| Vendor create/search/legacy edit | full | edit, claim, consolidate, images, docs, profile pages |
| Places CRUD + geocode | full | read-only `place` query, map, dialog (`place`, `place-dialog` modules, `camap-ts/packages/front-core/src/neo.tsx:108-113`) |
| Files serve (`/file/...`) + cron | HX | create/delete, no serving route, maintenance REST |
| Media (group gallery) | HX | none (TS `Vendor.media` is vendor-scoped) |
| Docs (PDF) | HX forms | `createDocument`/`deleteDocument` (+ vendor docs, TS-only) |

Both stacks write the same MySQL tables (Haxe SPOD vs TypeORM entities).
